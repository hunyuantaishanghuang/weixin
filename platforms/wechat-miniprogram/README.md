# 微信小程序端快速导入与运行指南

本目录为专为**微信小程序**打包好的标准原生项目，开箱即用。

---

## 🛠 3 步在微信开发者工具中运行

### 第 1 步：下载并打开微信开发者工具
- 下载官方微信开发者工具（Stable 稳定版）。
- 点击「导入项目」，选择当前目录：
  ```text
  /platforms/wechat-miniprogram
  ```

### 第 2 步：配置 AppID
- 如果已有已注册的小程序，填入您的真实 `AppID`；
- 如果只是先本地测试体验，可选择「测试号（AppID 会自动填入测试 ID）」。

### 第 3 步：配置业务域名（上线时必须）
1. 在微信开发者工具右上角点击「详情」->「本地设置」，勾选 **「不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书」**（开发阶段无需备案即可直接运行）。
2. 在正式发布上线前：
   - 如果使用微信云开发：无需购买域名、免 ICP 备案！直接在 `app.js` 初始化云开发即可。
   - 如果使用自建服务器：在微信小程序后台「开发管理」->「业务域名」中添加您的服务器 HTTPS 域名。

---

## 💡 为什么这种方案最适合您？
- **零额外代码量维护**：所有复杂的经期智能算法、浪漫点菜、多彩心情日记、留言板状态均由同一套代码驱动。
- **微信分享一键带参**：用户在小程序里点击右上角「分享给好友」，微信会自动带上双方的 `pairId` 识别码，伴侣点击卡片进入直接一步到位！
