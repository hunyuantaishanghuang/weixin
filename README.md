# 我们的小日子 · 情侣专属生活记录

基于情侣生活记录应用打造的现代化 Web 应用（React + TypeScript + Vite + Tailwind CSS），完整移植并保留了原版小程序的全部核心功能、温柔粉白浪漫视觉风格与双人数据隔离逻辑。

## 🌟 核心功能

1. **🍳 今日点菜**
   - 菜谱库：记录家常美味与做法备注，可快速一键「点给TA」
   - 今日点单：查看今日已点菜单，支持标记已完成 (✅)
   - 智能解析：支持粘贴整段菜谱或外链文本，智能提取菜名与原材料列表
   - 手动加菜：支持菜名、食材标签、做法备注与图片上传

2. **🌸 经期记录**
   - 周期与易孕期智能推算：基于过往记录自动计算平均经期周期（天数）
   - 智能倒计时：下次来临预测与倒计时提醒
   - 易孕期预测区间，温柔贴心
   - 历史记录管理与一键记一笔

3. **💭 心情日记**
   - 多彩心情标记（开心 😊、难过 😢、生气 😠、平静 😌、疲惫 😩、甜蜜 🥰）
   - 支持文字心得与多张照片上传预览
   - 时间线记录两人的日常小确幸

4. **💌 悄悄话留言**
   - 专属双人留言板，气泡消息实时交互
   - 「💗 来句情话」灵感助手：一键生成暖心情话与问候
   - 贴心视角切换：可随时在「我」与「TA」双重視角间切换，轻松体验互动

5. **💞 伴侣配对系统**
   - 6 位唯一识别码生成与验证
   - 发起方与加入方双向确认机制
   - 专属空间数据隔离与解绑管理

## 🛠 技术栈

- **前端框架**：React 19 + TypeScript
- **构建工具**：Vite 6 (端口 3000, 监听 0.0.0.0)
- **样式与设计**：Tailwind CSS v4 + 专属浪漫粉白渐变主题
- **图标体系**：Lucide React + Emoji
- **本地存储**：LocalStorage 双人数据隔离持久化，支持重置演示数据

## 🚀 启动与构建

```bash
# 启动开发服务器（默认端口 3000）
npm run dev

# 编译构建
npm run build
```
